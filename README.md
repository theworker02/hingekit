# hingekit

Hinge structured JSON kit payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/hingekit/

## Install / run

```bash
git clone https://github.com/theworker02/hingekit.git
cd hingekit
node src/cli.js
node --test
```
